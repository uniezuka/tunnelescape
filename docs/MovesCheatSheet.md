## Levels 5-7 detail

All three share the same shape: a fast 2-move route, a slower-but-still-correct 3-move route, and portals that loop you backward and waste moves. None of them are true dead ends — a wrong portal just costs you moves, it never blocks the level.

**Level 5 — Going in Circles**
- Fastest (2 moves): Red, Yellow → Potion Workshop → Exit
- Longer, still fine (3 moves): Green, Red, Red → Scriptorium → Vault → Exit
- Avoid: Scriptorium's Yellow and Vault's Green — both loop all the way back to the start

**Level 6 — The Long Way Round**
- Fastest (2 moves): Red, Yellow → Librarian's Office → Exit
- Longer, still fine (3 moves): Green, Green, Red → Astronomer's Study → Card Catalog Hall → Exit
- Avoid: Astronomer's Study's Yellow (loops all the way back to the start), Card Catalog Hall's Green (loops back to Librarian's Office)

**Level 7 — Crossed Paths**
- Fastest (2 moves): Red, Yellow → Children's Reading Room → Exit
- Longer, still fine (3 moves): Green, Red, Red → Crystal Repository → Reading Nook → Exit
- Avoid: Crystal Repository's Yellow (loops all the way back to the start), Reading Nook's Green (loops back to Children's Reading Room)
